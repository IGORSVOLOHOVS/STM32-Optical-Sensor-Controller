Detailed Description

Interrupt-based UART transport implementation.

Provides non-blocking UART communication using HAL_UART_Receive_IT(). Uses atomic flag for thread-safe communication between ISR and main loop.

Note
Uses USART1 (PC4/PC5) at 115200 baud
Packet size is fixed at 8 bytes

Example usage:

UartTransport transport;
transport.init();
if (transport.available()) {
uint8_t buffer[8];
if (transport.receive(buffer, 8)) {
// Process received data
}
}
