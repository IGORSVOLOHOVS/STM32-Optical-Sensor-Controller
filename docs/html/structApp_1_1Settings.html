Detailed Description

Configuration parameters for optical sensor system.

Contains all configurable parameters including sensor thresholds, debouncing delays, and device identification. All values can be modified at runtime via the communication protocol.

Threshold Logic:

  • emptyValue < transparentThreshold < nontransparentThreshold
  • EMPTY: ADC < transparentThreshold
  • FULL: ADC > nontransparentThreshold
  • EMPTY_TEMPORARY: Between thresholds with timeDelay
Note
All members have sensible defaults
Supports constexpr initialization
